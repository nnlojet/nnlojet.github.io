# NNLOJET website

Source repository for **https://nnlojet.github.io/**.

This is a complete website source tree, not a patch or an overlay. It combines
the existing static NNLOJET website with the release-paper sources and a
GitHub Actions workflow. No Jekyll, Node.js, Ruby, or website framework is used.

**Start with [SETUP.md](SETUP.md)** for repository creation and publishing.
See [VALIDATION.md](VALIDATION.md) for the local test results and limitations.

## Editing

- Website content: `web/*.html` (ordinary page fragments).
- Shared layout: `web/TEMPLATE.html`; styling: `web/index_files/`.
- Manual: `manual/NNLOJET.tex`, its bibliography, and its figures.
- Release-download destinations: `web/releases.html`.

The manual HTML, its PDF, and the final website are generated in CI. Do not
commit `_build/` or `web/autogenerated/`; they are ignored by Git.

## Publishing

Push or merge to `main` to build and publish. Pull requests targeting `main`
run the same build and local-link checks but do not deploy.
The workflow is `.github/workflows/pages.yml`. Only `web/autogenerated/` is
uploaded to Pages. No deploy key or user-supplied token is needed.

## Release packages

The supplied source archives did not include `nnlojet-v1.0.0.tar.gz` or
`nnlojet-v1.0.2.tar.gz`. Their links now point to their original absolute
HEPForge URLs, so they are not required to build or publish this website.
Those legacy downloads have not been independently verified here.
Move them to GitHub Releases and edit `web/releases.html` when migrating
software distribution. No placeholder software archives are included.

## Manual provenance

All 93 substantive files from `NNLOJET_code_arXiv_v2.tar.gz` are included
byte-for-byte under `manual/`; only macOS metadata was excluded.
`MANUAL-SOURCES.sha256` records their initial checksums. It is a provenance
snapshot, not a CI check that prevents future manuscript edits.
Existing copyright and licensing notices are retained. This packaging does
not assign a new license to the scientific manuscript or website content.
