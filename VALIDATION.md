## Deliberate changes relative to the previous overlay kit

The original website and the v2 manual-generation kit are now in one source
tree. Old generated `web/manual*.html` fragments and the stale source copy of
`web/index_files/lwarp.js` are omitted: CI regenerates their replacements.
The separate original manuscript under root `manual/` remains untouched.

The two absent release archives are no longer a build blocker because their
relative links in `web/releases.html` have been resolved against the original
HEPForge hostname. The page labels them as hosted there. They are not fake
files, bundled code releases, or verified new GitHub Release URLs. The strict
local-file checks are still enabled for any genuinely local links.

No generated `_build/` or `web/autogenerated/` output, macOS metadata, local
toolchain workarounds, or Git history belongs in the tarball. Hidden `.github/`
and `.gitignore` configuration is included.

## Environment and remaining integration checks

Local compilation used Debian, TeX Live 2025/dev, pdfTeX 1.40.26, latexmk 4.86,
lwarp/lwarpmk 0.918, and lxml 6.1.1. A local broken BibTeX executable link was
worked around outside the repository with the already-installed original
executable; this local workaround is not shipped.

The workflow installs Ubuntu 24.04 distribution packages. The actual
GitHub-hosted runner, its dependency installation, and the Pages upload/deploy
steps have not been executed here. The first GitHub run remains an integration
test, particularly for differences between TeX/lwarp versions.

Action release references were checked against the official GitHub release
pages: checkout v7.0.1, configure-pages v6.0.0, upload-pages-artifact v5.0.0,
and deploy-pages v5.0.1. These are version tags, not immutable commit SHA pins.

The legacy HEPForge release downloads could not be independently verified
through the available access. Their URLs are derived from the user's original
website files. Check them in a normal browser before announcing the site, and
move software distribution separately when ready.

The local validator does not fetch external links, parse CSS dependency URLs,
or evaluate browser-side JavaScript. MathJax remains the existing external
CDN dependency (now selected at version 3.2.2). Publication does not verify
third-party service availability or the scientific content of the manual.

No GitHub repository, settings, DNS records, or live website were changed.
