# Website source files

Edit ordinary pages here, the shared `TEMPLATE.html`, and `index_files/nnlojet.css`.
Edit the manual in `../manual/NNLOJET.tex`, not in generated HTML.

From the repository root, with the dependencies listed in `../SETUP.md`:

```bash
bash web/make_manual.sh
python3 web/update.py
python3 web/check_site.py
```

Publish only `web/autogenerated/`. The GitHub Actions workflow does this
automatically.

The example runcards are stored in `runcards/<PROCESS>/<name>.run`, one folder
per process of `NNLOJET --listprocs`. After adding or editing a runcard,
regenerate the examples page with `python3 web/prepare_examples.py` and commit
both the runcard and `examples.html`; the script is not run in CI. Runcards
named `nnlojet-<arXiv>-...` use the setup of an NNLOJET publication, runcards
named `<experiment>-<arXiv>` the fiducial setup of a measurement; any other
runcard should explain its setup in a header comment, whose first sentence is
shown on the page. The results of previous runs in `example_runs/` are kept but
not published until they have been checked.
