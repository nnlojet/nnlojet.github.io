Examples

Example runcards for all processes available in NNLOJET v1.0.3. Runcards named nnlojet-<arXiv>-... use the setup of an NNLOJET publication, runcards named <experiment>-<arXiv> the fiducial setup of a measurement; the other runcards are illustrative setups, described in their header comments.

Every runcard can be run directly, e.g. NNLOJET --run Z/atlas-1109.5141.run, which computes the leading-order contribution (LO) selected in the CHANNELS block. The higher-order contributions are selected in the CHANNELS block, as explained in the comment there, together with suitable warmup and production settings. Alternatively, the complete calculation can be run with the nnlojet-run workflow, see the manual. The PDF sets used in the runcards must be installed in LHAPDF.

Runcard features

Example runcards that use specific runcard options:

  • Proton-antiproton collisions (collider = PAP): WM/d0-1309.2591.run, WP/d0-1309.2591.run, Z/cdf-0908.3914.run
  • Lepton-proton collisions with beam energies (collider = PE, Ebeam1, Ebeam2): epLJ/hera-NC-incl-jets-lab.run, epNbJ/hera-CC-incl-jets-lab.run, epNbJJ/hera-CC-dijets-breit.run
  • Polarised lepton beam and Z-boson exchange (pol, V_NC): epLJ/hera-NC-incl-jets-lab.run
  • Z boson decaying to neutrinos (L_NC = NU): ZJ/Znunu-monojet13TeV.run
  • Exclusive jet multiplicity (jet_exclusive = .true.): eeJJ/2jet-rate-durham-mZ.run, HTO2L2NJ/Hto2l2nJ13TeV.run
  • Durham and JADE jet algorithms for electron-positron collisions: eeJJ/2jet-rate-durham-mZ.run, eeJJJ/event-shapes-mZ.run
  • Photon isolation (photon_isolation): GJ_frag/GJfrag13TeV-cone.run, HTO2P/Hto2p8TeV.run, GG/atlas-2107.09330.run
  • Photon fragmentation (photon_fragmentation): GJ_frag/GJfrag13TeV-cone.run
  • Automatic warmup schedule (warmup = <ncall>[auto]): ZJ/Znunu-monojet13TeV.run
  • Multi-channel sampling and other optimisation settings (multi_channel): JJ/nnlojet-2412.21165-CMS8TeV.run, epLJJ/nnlojet-1703.05977-ZEUS1j.run, epLJJ/nnlojet-1703.05977-ZEUS2j.run
  • Scale coefficients and histogram scale overrides (scale_coefficients, mu0): epLJJ/nnlojet-1703.05977-ZEUS1j.run
  • Complex-mass scheme for the W and Z bosons (SCHEME[GV] = CMS): GG/atlas-2107.09330.run, WM/atlas-1109.5141.run, WM/atlas-1603.09222.run
  • Fixed electroweak coupling (SCHEME[ALPHA] = FIX): GJ_frag/GJfrag13TeV-cone.run, GJ/nnlojet-1904.01044-Ginc.run, GJ/nnlojet-1904.01044-GJ.run
  • Electroweak coupling at the Z pole (SCHEME[ALPHA] = ALPHAMZ): eeJJ/2jet-rate-durham-mZ.run
  • Full CKM matrix (CKM = FULL): WM/atlas-1109.5141.run, WM/atlas-1603.09222.run, WM/atlas-1612.03016.run
  • Vetoes with reject selectors: GJ_frag/GJfrag13TeV-cone.run, GG/atlas-2107.09330.run, GJ/nnlojet-1904.01044-Ginc.run
  • Selector groups (OR ... END_OR): eeJJJ/event-shapes-mZ.run
  • Selectors applied only to valid observables (select_if_valid): ZJ/Znunu-monojet13TeV.run
  • Histogram selectors (HISTOGRAM_SELECTORS): epNbJJ/hera-CC-dijets-breit.run, epNJJ/hera-CC-dijets-breit.run, GJ_frag/GJfrag13TeV-cone.run
  • Composite histograms (COMPOSITE): epLJJ/nnlojet-1703.05977-ZEUS1j.run, JJ/nnlojet-2204.10173-JJFCCMS.run, Z/atlas-1612.03016-CF.run
  • Fiducial cross sections (cross > <name>): eeJJ/2jet-rate-durham-mZ.run, ZJ/Znunu-monojet13TeV.run, HTO2L1PJ/nnlojet-2111.02157-HTO2l1pJ13TeV.run
  • Cumulant distributions (cumulant): eeJJJ/event-shapes-mZ.run, ZJ/Znunu-monojet13TeV.run
  • Logarithmic binning (binning = LOG): eeJJJ/event-shapes-mZ.run
  • Breakdown into partonic luminosities (output_type = 1): ZJ/Znunu-monojet13TeV.run, GG/atlas-2107.09330.run
  • Rescaling a histogram (fac): eeJJ/2jet-rate-durham-mZ.run
  • Biasing the phase-space sampling (REWEIGHT): JJ/nnlojet-2412.21165-CMS8TeV.run, epLJJ/nnlojet-1703.05977-ZEUS1j.run, epLJJ/nnlojet-1703.05977-ZEUS2j.run
  • PDF interpolation (PDF_INTERPOLATION): epLJJ/nnlojet-1703.05977-ZEUS1j.run, epLJJ/nnlojet-1703.05977-ZEUS2j.run
